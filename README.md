# Numerai Tournament — Quantitative Machine Learning

**Independent Quantitative Research | Machine Learning | Financial Data Science**

## Overview

This repository documents my participation in the **Numerai Tournament**, a global machine learning competition focused on financial prediction.

The project involves developing, evaluating, and submitting proprietary machine learning models designed to identify predictive signals in financial data.

The implementation is kept private to protect the models' underlying alpha.

## What is Numerai?

[Numerai](https://numer.ai) is a quantitative hedge fund that organizes a machine learning tournament where data scientists develop predictive models using financial market data provided by the platform.

Participants train models to predict the future relative performance of stocks and submit their predictions to the tournament.

Predictions are evaluated using several metrics, including:

- **CORR60 (Correlation):** Measures the relationship between model predictions and realized targets on 60 days span.
- **MMC60 (Meta Model Contribution):** Evaluates the contribution of a model's predictions beyond the information already captured by Numerai's aggregated Meta Model.

Numerai combines predictions from participating models to support its investment process.

## My Work

My participation involves developing and evaluating machine learning models for financial prediction, with particular attention to historical validation and performance consistency.

The research workflow includes:

- **Data Processing:** Working with Numerai's financial datasets using Python, NumPy, and pandas.
- **Predictive Modeling:** Developing machine learning models to generate predictions from financial features.
- **Model Validation:** Evaluating predictive performance across different historical periods (eras).
- **Performance Analysis:** Analyzing correlation and model contribution metrics.
- **Live Tournament Participation:** Submitting predictions to Numerai and assessing live model performance.

The objective is to develop predictive signals that remain effective across different market periods.
